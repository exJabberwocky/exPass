# exPass — Локальный зашифрованный менеджер паролей

**exPass** — это современная десктопная альтернатива классическим менеджерам паролей, сочетающая надежность стандарта KeePass с визуальной эстетикой и плавностью современных операционных систем.

Приложение спроектировано для тех, кто не готов доверять свои цифровые секреты закрытым облачным сервисам, но устал от архаичных интерфейсов традиционных утилит.

---

### Ключевые преимущества

* **Приватность по умолчанию:** Ваши пароли принадлежат только вам. База хранится в стандартном формате `.kdbx` локально на диске или в синхронизируемой вами папке. Никаких обязательных аккаунтов, трекеров и облачных подписок.
* **Глубокая интеграция с ОС:** exPass органично вписывается в окружение Windows 11 благодаря поддержке системных материалов Mica и Acrylic с динамической калибровкой прозрачности под светлую и тёмную темы.
* **Активируемый парящий стиль (Island Layout):** Панели навигации и список записей выполнены в виде независимых парящих карточек с мягкими тенями, обеспечивая визуальную легкость при работе.
* **Быстрый доступ и клавиатурный поток:** Интерфейс оптимизирован для работы без мыши: поиск вызывается по `Ctrl+K`, очищается по `Esc`, а переход по категориям и записям осуществляется стрелками.
* **Умный генератор и история:** Создавайте случайные криптостойкие или запоминающиеся пароли в один клик. Вся история изменений сохраняется в структуре базы — вы всегда можете вернуть предыдущий пароль из ревизий.
